# Scripts

Dejad aquí los trabajos, consultas o programas que ejecutéis: mapper y reducer, SQL, pipeline, o el cliente de recepción.

Cada evidencia debe citar el archivo y la versión con la que se obtuvo la salida. Un script sin la salida contrastada no acredita el criterio. Una salida sin el comando tampoco.

No subáis contraseñas. Si un comando necesita una clave, leedla de una variable de entorno y dejad un `.env.example` sin valores reales.
