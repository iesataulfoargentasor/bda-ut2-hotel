# Salidas

Las salidas grandes del cálculo se quedan en esta carpeta y no se suben. En la evidencia de cada bloque pegad el extracto que permite contrastar el total, el estado del nodo o el tiempo.

Si una salida cabe en unas pocas líneas y hace falta para leer el expediente sin repetir el job, podéis copiarla dentro del markdown de `evidencias/`.
