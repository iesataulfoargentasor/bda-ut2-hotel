# Datos

El profesor publica en Moodle el generador y `totales_esperados.json`.

1. Copiad `totales_esperados.json` en esta carpeta y subidlo. Es pequeño y fija noches e importe por hotel, cancelaciones por canal y recuentos de sensores.
2. Generad el bruto en `datos/bruto/` o dejadlo en `datos/generado/`. Esas carpetas no se suben.
3. Anotad en cada evidencia la ruta local y el tamaño medido.

No cambiéis la semilla ni el fichero de totales para hacer coincidir un resultado. Si el total sale distinto, revisad la lectura, el filtro del cierre y la agregación.
